# Система учёта складских товаров (Warehouse DevSecOps)

## Описание системы
Проект представляет собой микросервисную систему для учёта товаров на складе. Система позволяет добавлять товары в каталог, оформлять их приход и получать уведомления о действиях.

## Архитектура
Система состоит из следующих компонентов:
*   **API Gateway** — единая точка входа для клиентов.
*   **Products Service** — управление каталогом товаров (сохранение в PostgreSQL).
*   **Stock Service** — операции с остатками (приход), обращается к Products и Notifications.
*   **Notifications Service** — имитация отправки уведомлений (пишет логи в консоль).
*   **PostgreSQL (db)** — база данных, запускается в отдельном контейнере с volume `db_data`.

Схема архитектуры (C4) находится в папке `docs/`.

## Технологии
*   Python 3.11 (FastAPI, SQLAlchemy)
*   PostgreSQL 16
*   Docker, Docker Compose
